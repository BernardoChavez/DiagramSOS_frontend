# DiagramSOS Frontend

Frontend en React y Vite para el sistema de diseño de base de datos DiagramSOS.
Desarrollado para despliegue en Vercel.

## Comandos locales
- `npm install`
- `npm run dev`
- `npm run build`

## Variables de entorno necesarias en Vercel
- `VITE_API_URL`: URL del backend en producción (ej. `https://diagramsos-backend.up.railway.app/api`)
